# Pathfinding Algorithms Visualizer

Pathfinding Algorithms Visualizer is an interactive web application for visualizing popular pathfinding algorithms like BFS, DFS, A* Search, and more. The app allows users to create custom mazes, choose starting and ending points, and watch the selected algorithm find a path step by step. This project is implemented in Svelte.

## Live Demo

You can explore the app live at: [Pathfinding Algorithms Visualizer](https://pathfinding-web.vercel.app)

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later recommended)
- `npm`, `yarn` or `pnpm`

### Installation

1. Clone the repository:

2. Install dependencies:

   ```bash
   pnpm install
   ```

## Development

Start a local development server:

```bash
pnpm run dev
```

This will launch the app at [http://localhost:4200](http://localhost:4200). Changes made to the source code will be reflected automatically in the browser.

## Building for Production

To build the project for production:

```bash
pnpm run build
```

The production-ready files will be output to the `dist` folder.

Preview the production build:

```bash
pnpm run preview
```
